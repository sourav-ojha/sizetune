# GRO-008: Ship four per-form pages (SSC, IBPS, GDS, PAN) using verified specs

## Goal
Exam-specific queries are served by one-page-per-exam sites that disagree on specs; SizeTune has none. India SERPs are unobserved, so build only after GRO-004 records them and GRO-007 verifies specs. Start with four pages, each with a spec table, preset and steps; check indexing before adding more. Approved growth roadmap item (weeks 5-8).

## Acceptance criteria
- AC1: Given GRO-004 has recorded India-served results for the four exam queries, When a query is dominated by national exam publishers, Then that page is dropped or deferred
- AC2: Given the human spec verification is recorded, When each page is built, Then it shows the official spec with source and date and a preset that matches it
- AC3: Given the four pages, When read, Then each has unique instructions, not only a changed number
- AC4: Given the hub or tools page, When built, Then it links all four exam pages

## Non-goals
- Nothing beyond this item. No publishing, posting, directory submissions, account creation or ads changes unless an acceptance criterion says so.
