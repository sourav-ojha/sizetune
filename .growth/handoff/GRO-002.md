# GRO-002: Link every tool page to its guide and link the orphan guide

## Goal
The live 50 KB page links only to the guides hub; about 24 tool pages have no specific guide link and the 200 KB PDF guide has only guide-to-guide inbound links. Tool to guide to tool links help crawling and ad-quality content depth. Approved growth roadmap item (weeks 1-4).

## Acceptance criteria
- AC1: Given any tool page, When it renders, Then it shows at least one link to a relevant specific guide, not only the hub
- AC2: Given the reduce-pdf-to-200kb guide, When the site is built, Then at least one non-guide page links to it
- AC3: Given the build, When verify:html runs, Then it passes

## Non-goals
- Nothing beyond this item. No publishing, posting, directory submissions, account creation or ads changes unless an acceptance criterion says so.

## Constraints and assumptions
- Evidence: fact, medium confidence. Sources: S-037 https://sizetune.com/resize-image-to-50kb/; S-040 repo:src/content/guides; S-043 repo:src/data/tools.ts.
- Risk: Links added to unrelated guides add noise; keep them topical
