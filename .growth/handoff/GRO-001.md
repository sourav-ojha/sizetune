# GRO-001: Update privacy copy and add privacy-friendly usage analytics

## Goal
No analytics or tool events exist, so organic landing pages, tool success and download rates cannot be measured; referrals from distribution cannot be attributed. Privacy copy must change before any analytics or ads, per the owner constraint. Approved growth roadmap item (weeks 1-4).

## Acceptance criteria
- AC1: Given the privacy page is updated, When a visitor reads it, Then it states which analytics run, what is collected and that images are never sent anywhere
- AC2: Given a visitor completes a resize, When the tool succeeds or fails or the file is downloaded, Then an event with tool name and outcome (no file data) is recorded
- AC3: Given the network tab is open on a tool page, When an image is processed, Then no request carries image bytes

## Non-goals
- Nothing beyond this item. No publishing, posting, directory submissions, account creation or ads changes unless an acceptance criterion says so.

## Constraints and assumptions
- Evidence: fact, high confidence. Sources: S-036 https://sizetune.com/; S-038 https://sizetune.com/privacy/; S-045 repo:.product/PRODUCT.md.
- Risk: Tool choice (cookieless analytics vs GA4 with consent) changes the consent needs; "nothing is uploaded" trust copy must stay true
- Design is open: explore it with the brainstorming skill before implementing.
