Social platforms publish image sizes on their help pages, and blogs repeat them, often with different numbers. SizeTune's social resizers only offer a size when the platform's own help page states it. This page lists every preset, the page it came from and the date we last read it, so you can judge how fresh a number is and check it yourself.

*Published and last updated 17 November 2026 by SizeTune.*

## How the presets are chosen

A size is added only if we could read it on an official page of the platform: Instagram's Help Center, LinkedIn Help or YouTube Help. Sizes from third-party guides are not used, because those guides disagree with each other and with the platforms, and they are not updated when a platform changes. Where an official page was unclear or its text differed between versions, the size is left out. For example, LinkedIn's company Page cover image is not offered, because LinkedIn's help text and older guides give different numbers for it.

## What is not offered

Instagram's Help Center pages we read do not state a pixel size for Stories or for a profile picture, so there are no presets for them. LinkedIn's pages did not give a size we could verify for a personal profile photo, so that is absent too. If a platform later publishes one, it can be added in one place and every page that uses it updates together.

## Why the date matters

Platforms change their rules. YouTube's file size limit for thumbnails, for example, is stated separately for mobile and for desktop, and sizes on other sites may lag behind. The checked date is when we last read the page. If it is old, open the official page and compare before you rely on a number, and if the numbers differ, trust the platform.
