# Directories to submit SizeTune to

FEATURE-012 FR-4. Submitting is the owner's action; nothing here has been submitted. Names come from the research notes in
FEATURE-012 (OPP-034). Check each site's current rules and form before you submit: submission steps change and were not
verified when this file was written.

## Before you submit
1. Confirm the tool hub (`/tools/`) is live and linked from the main navigation.
2. Prepare one short description (under 160 characters), one long description, the logo (`/favicon.svg`) and two screenshots.
3. Use the canonical address `https://sizetune.com/` and say plainly that files are processed in the browser.

## List
| Directory | What to submit | Steps | Status |
|---|---|---|---|
| AlternativeTo | The site as an alternative to image compressors and resizers | Create an account, use "Suggest new app", fill in name, description, tags, link | not submitted |
| Toolify | The site as an AI-free online tool | Use the site's "Submit" form, give name, URL, description | not submitted |
| Product Hunt | One launch post for the tool collection | Make an account, schedule a launch with tagline, gallery and first comment | not submitted |
| Other free-tool or app directories | The same short and long description | Search for current lists; skip any that require a paid link | not submitted |

## Rules for ourselves
- Submit one listing per directory; do not buy links or exchange links.
- Keep the description identical to what the site does today; update listings when a tool is added.
- Record the date and the listing URL in the Status column once submitted.
